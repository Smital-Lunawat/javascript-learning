# JavaScript Learning

A growing collection of JavaScript concepts, exercises, and implementations created while learning the language.

## Topics

| # | Topic | Concepts |
|---:|---|---|
| 1 | [Array method polyfills](01-array-methods/polyfills.js) | Callbacks, `this`, prototypes, `map`, `filter`, and `reduce` |
| 2 | [Student array practice](02-array-practice/students.js) | For loops, `map`, `filter`, `reduce`, and arrow-function returns |
| 3 | [Currying practice](03-currying/currying.js) | Basic currying, reusable functions, infinite currying, and DOM updates |

## Run the examples

Install [Node.js](https://nodejs.org/), clone this repository, and run:

```bash
node 01-array-methods/polyfills.js
node 02-array-practice/students.js
node 03-currying/currying.js
```

Open `03-currying/dom-example.html` in a browser to run the DOM example.
